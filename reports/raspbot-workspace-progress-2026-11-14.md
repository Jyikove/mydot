## 三处工作区

以下只列各自项目根目录内的相对路径。三处不是同一个同步盘。

### Mac：编辑和查看的主工作区

```text
三维仿真/
├── 脚本/   # 运行源码、配置、依赖锁、静态检查入口
├── 视频/   # 最新一轮验收的四段成片（改字前）
├── 报告/   # 验收报告、迁移和静态核查
└── 资产/   # 场地、小车、推板及棋子的运行资产
```

旧工作区已移出活跃目录，可恢复。Mac 上可从项目根目录运行 `python3 脚本/静态检查.py` 做静态检查；完整仿真仍以服务器的隔离运行环境为准。

### 仿真服务器：实际运行和复现

```text
仿真项目根目录/
├── active/     # 指向 releases/field47_white_20261114_v3_cannon/
├── releases/   # 版本化的源码、配置和运行资产；留有可回滚版本
├── runtime/    # 隔离运行环境
├── runs/       # 运行输出
├── reports/    # 私有验收记录
└── archive/    # 退役资产归档
```

运行资产以 `active/` 下的发布版本为准。顶层 `assets/` 是旧归档的兼容链接，不是当前资产目录。这是工作入口简图，不是服务器文件系统清单。运行前先核对活动版本和独立输出目录，不覆盖历史验收。旧硬件与运行环境信息不纳入此公开报告。

### Dot 云端：协调与文档

```text
当前工作区/
└── 未发现一份可独立运行的 RASPBOT 仿真副本

GitHub 协作仓库/
├── plan.md
```

Dot 云端用于梳理计划、核对和提交文档。早期接口原型见 [仿真 PR #3](https://github.com/Jyikove/mydot/pull/3)，不等同于当前可运行版本。完整运行包、视频和原始资产仍由 Mac 和仿真服务器管理。本报告只记录进度与状态，不包含这些运行文件。

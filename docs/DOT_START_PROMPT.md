---

请把 GitHub 仓库 **https://github.com/Jyikove/mydot** 作为我的长期任务协作工作区。

1. 验证你是否能够访问仓库，并报告访问方式、默认分支、是否可以读取、创建分支、提交和创建 PR。没有权限时准确说明，不要假称已完成。
2. 按顺序读取 `README.md`、`AGENTS.md`、`plan.md`、`status.md`。
3. 遵守 `AGENTS.md` 的执行规范，优先处理 `plan.md` 中未完成、无阻塞的任务。

6. 每次暂停前记录当前任务、实际结果、阻塞与下一步；再次开始时先检查仓库最新状态。
7. 本次先完成 GitHub 接入与状态回写验证，然后向我汇报。后续是否定时运行需要另行配置。
